01 / 모델 준비

대화 시작하기

처음 한 번 모델 파일을 브라우저로 불러옵니다. 인터넷과 PC 성능에 따라 수 분 걸릴 수 있습니다.

아직 모델을 불러오지 않았습니다.
Qwen2.5 0.5B Instruct브라우저에서 실제 모델을 실행합니다.준비된 답변을 보여 주는 시연이 아닙니다.

PC용 보고서의 1.5B 모델과 크기가 다릅니다. 작은 모델은 한국어 표현이나 사실 설명에서 오류를 낼 수 있습니다.

사용 환경과 출처

최신 Chrome 또는 Edge의 PC 환경을 권장합니다. GPU를 사용할 수 없으면 CPU로 실행합니다. 모델은 Hugging Face, 실행 라이브러리는 jsDelivr에서 다운로드합니다. 입력한 대화는 이 페이지에서 처리하며 별도 대화 서버에 전송하지 않습니다.
